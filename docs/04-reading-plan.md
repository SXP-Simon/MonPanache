# 04 · 阅读路线与行动清单

以下是学习建议，不是官方课程顺序或成绩承诺。材料编号见[20 讲目录](../materials/README.md)。

## 第一遍：用约一小时建立全貌

1. 读[比赛速览](01-competition-overview.md)，先记住本届日期、三类题目及正式规则的获取需求。
2. 看 T01“大赛介绍”的赛制部分，再看 T04“对话”对项目价值的讨论；历史、宣传数字可以暂时略读。
3. 看 T05“seekdb 基础”和 T10“PowerContext 介绍”，建立两者分工。
4. 看[方向对照表](02-tracks-and-topics.md)，选 1 个主方向和 1 个备选。

TXT 适合快速浏览；需要核实具体措辞或视频位置时查同名 SRT。短 TXT 往往是精简稿，不能假定包含所有原话。

## 正式题面到手后怎样拆解

为每个考虑实现的题记录以下内容即可，不需要先写很长的设计文档：

```text
题名 / 官方链接 / 题面版本：
所属项目 / 指定分支或 commit：
分值与计分规则：
输入、输出及禁止事项：
依赖功能与资源：
最小可行实现：
本地验证方法：
官方提交与复现步骤：
当前阻塞：
```

先做到可以提交和复现，再进行性能或效果优化。对于应用 / 上下文方向，比较基线与改进方案时尽量固定数据、模型和预算，避免把模型升级误判为自身改进。

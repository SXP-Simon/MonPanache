高德这个方向的赛题是构建一个持续进化的个人位置智能体，这是一个类似于旅行规划的空间智能应用。

这里边其实是一个非常实际的业务应用。作为高德开放平台，其实跟很多的客户和开发者其实都服务过类似的应用。它其实是一个针对旅行的规划，依靠去哪些地方、停留、时间、用户的偏好计划等等。像小红书、携程、高德本身，其实都在做类似的空间规划场景。

旅行规划里面其实有三个复杂的点：
第一是空间计算非常复杂。高德在传统的路径规划上，从起点到终点去做一条合适的路线规划已经是一个比较复杂的事情了。旅行规划是多个候选目的地，又有可选的地方，又有里边的游览路线、多种交通方式等等。从数据计算量来说，是一个复杂的图形设计，空间计算本身就是一个比较复杂的点。
第二是数据和决策比较复杂。用到了海量的数据，而且分散在非常多的位置上。旅行规划中的兴趣点（POI 点）是重要的元素，POI 点的吸引力分布在不同的应用和用户的偏好中。这里边有路网、有热力、有分段的信息（比如景点什么时候拥堵、中间的道路是否合理等空间关系）。数据相对来说比较难穷举，目前可能还没有任何一个平台能把所有需要的数据归拢在一起。
第三是产品交互复杂。在让 Agent 去做旅行规划的时候，目前单日规划 Agent 已经做得比较 OK 了，但是到底怎么去选合适的旅行规划、有什么偏好、什么样的规划是真正能吸引用户的？这是行业内的难点。信息展现太多容易造成过载，展现太少又缺少丰富性和复杂性。

高德能提供的能力有三类：
1. 空间计算能力：高德开放平台开放了路径规划等空间计算能力，支持多点+点线面的空间计算，支持拼接与计算；
2. 数据决策能力：高德提供丰富的空间数据（地点 POI、路网、交通情况、实时拥堵、面数据等）；
3. 空间表达能力：提供地图展现和可视化能力。

高德 API 是原子的能力，对于 Agent 来说能不能调用好、更好地理解决定了效果。数据的丰富程度决定了分析的深度与真实度。一方面可以从高德 API 获取精准有效的数据，另一方面也可以结合网络公开数据进行清洗补充。

空间分析很适合用 Workflow 去逐项解决。
案例分享：
- 案例一：适合开店的临街路况分析（结合点线面、道路属性、人流与车流热力数据）；
- 案例二：人流热力与区块划分（将人流热力划分为不同区块，高亮中心兴趣点规划游玩路线）。

高德开放平台业务全景：
- 基础服务：地图、搜索、驾车、货车、公交、步行、骑行等点线面能力；
- 高级服务：MCP 等 AI 类能力与行业解决方案（网约车、两轮车等）；
- 数据可视化：点/线/面/3D 数据展现，轨迹能力（人与车轨迹、电子围栏等）；
- AI 相关能力：通过自然语言生成答案，提供点位、客流画像与分析决策能力。
